21  Working with AI Assistants

21.1 Learning Objectives

By the end of this chapter, you will be able to:

  • Understand what AI programming assistants are and how they work
  • Choose the right AI tools for Python development
  • Craft effective prompts using intentional prompting
  • Use AI to debug code and generate tests
  • Evaluate the quality of AI-generated code
  • Recognise when AI assistance is and is not appropriate

21.2 1. Understanding AI Programming Assistants

AI programming assistants are tools powered by large language models (LLMs) that can understand and generate code. They range from autocomplete features to conversational assistants that write code from natural language descriptions.

They fall into several categories:

  • Code completion tools — suggest code as you type (GitHub Copilot, Cursor)
  • Conversational assistants — generate code from dialogue (Claude, ChatGPT, Gemini)
  • IDE integrations — AI features built into your editor (VS Code Copilot, JetBrains AI)
  • Code explanation tools — help you understand existing code

These systems are pattern-matching tools trained on vast repositories of code. They predict what code is likely appropriate in a given context — they do not “understand” code the way humans do.

TipAI Tip

When choosing an AI assistant, start with a conversational tool (Claude, ChatGPT) for learning, and add an IDE tool (Copilot, Cursor) when you are writing code regularly.

21.3 2. Intentional Prompting

The quality of AI output depends on the quality of your input. Intentional prompting means crafting your requests with specific goals and context in mind, rather than asking vague questions.

Compare these prompts:

Help me with dictionaries
Show me how to create a Python dictionary that
maps student names to their test scores, then
find the student with the highest score.

The second prompt gives the AI context, a specific goal, and a clear expected output. This is intentional prompting.

21.3.1 The Five-Step Framework

  1. Define your objective — what exactly do you need?
  2. Provide context — what are you building? What do you already have?
  3. Set constraints — Python version, libraries, style preferences
  4. Format your prompt — structure it clearly
  5. Specify the output — code, explanation, comparison, or all three?

21.3.2 Prompt Template

I'm working on [brief context about your project].

I need to [specific objective] that will
[intended purpose].

Requirements:
- [constraint 1]
- [constraint 2]
- [constraint 3]

Please provide [what you want: code, explanation,
or both].

21.4 3. Prompting Patterns for Programming Tasks

Different tasks benefit from different prompt structures:

Concept exploration:

Explain how Python dictionaries handle hash
collisions. Use a simple analogy, then show
a code example.

Implementation:

Write a Python function that reads a CSV file
and returns a dictionary mapping column headers
to lists of values. Include error handling for
missing files and malformed rows.

Debugging:

I'm getting a TypeError on line 12. Here's my
code and the full error message:

[paste code and error]

What's causing this and how do I fix it?

Code review:

Review this function for correctness, efficiency,
and readability. Suggest specific improvements:

[paste code]

21.5 4. Advanced Prompting Techniques

As you gain experience, these techniques produce better results:

Chain-of-thought — ask the AI to reason step by step:

Let's think through this step by step:
1. What are the inputs and outputs?
2. What algorithm should we use?
3. What edge cases should we handle?
4. Now implement it in Python.

Comparative — ask for multiple approaches:

Show me three ways to sort a list of
dictionaries by a specific key. Compare their
performance and readability.

Role-based — set a perspective:

As a code reviewer focused on security, review
this function that handles user input.

Iterative refinement — build through conversation:

[First prompt]: Write a basic email validator.
[Follow-up]: Now add domain validation.
[Follow-up]: Refactor it into a class with unit
tests.

Iterative prompting typically produces better results than trying to specify everything in a single prompt.

21.6 5. Debugging with AI Assistance

AI excels at diagnosing errors when you provide structured context:

21.6.1 Error Message Analysis

I'm getting this error:

TypeError: unsupported operand type(s) for +:
'int' and 'str'

Here's the relevant code:

total = 0
for item in data:
    total = total + item["price"]

The data comes from a JSON file. What's wrong?

The key is providing: the error message, the code, and the context about where the data comes from.

21.6.2 Generating Test Cases

Write pytest tests for this function, including
edge cases for empty input, None values, and
boundary conditions:

[paste function]

AI-generated tests are a good starting point, but review them — AI often writes tests that pass trivially or miss actual business logic.

21.6.3 Systematic Debugging

When an error is hard to reproduce, ask AI to help you narrow it down:

This function works for most inputs but
occasionally returns wrong results. Help me
identify what inputs could cause issues:

[paste function]

21.7 6. Evaluating AI-Generated Code

Never accept AI-generated code without review. Use this checklist:

  1. Correctness — does it actually solve the problem?
  2. Edge cases — does it handle empty input, None, boundary values?
  3. Efficiency — is the algorithm appropriate for the data size?
  4. Security — does it validate input? Any injection risks?
  5. Readability — would another developer understand this?
  6. Style — does it follow Python conventions (PEP 8)?
  7. Dependencies — does it import anything unnecessary?
  8. Error handling — does it fail gracefully?

When you find issues, make specific refinement requests:

This code doesn't handle the case where the
input list is empty. Can you add a guard clause
at the beginning of the function?

21.8 7. Limitations and When Not to Use AI

AI programming assistants have significant limitations:

  • Knowledge cutoffs — may not know about recent libraries or API changes
  • Hallucinations — can confidently produce code that calls functions that do not exist
  • Context limits — cannot see your entire project; may suggest code that conflicts with your architecture
  • Security blindspots — may generate code with vulnerabilities
  • Over-engineering — tends to suggest complex solutions when simple ones suffice

21.8.1 When to be cautious:

  • Security-critical code — authentication, encryption, input sanitisation
  • Performance-critical paths — AI often chooses readable over fast
  • Domain-specific logic — AI does not know your business rules
  • Novel problems — AI recombines patterns it has seen; truly new problems need human thinking
Warning

AI-generated code can look correct while being subtly wrong. The more you understand Python fundamentals, the better you can spot these issues. This is why the earlier chapters in this book matter — they give you the knowledge to evaluate what AI produces.

21.9 8. Ethical Considerations

  • Attribution — if you use substantial AI-generated code, follow your context’s attribution practices (academic, professional, open source)
  • Skill development — use AI to accelerate learning, not bypass it. Understanding the code AI generates is essential.
  • Responsibility — you are responsible for code you ship, regardless of who or what generated it
  • Over-reliance — build your own problem-solving skills. AI is a collaborator, not a replacement for understanding.

21.10 9. Project Corner: AI-Enhanced Chatbot

Let’s enhance the chatbot with AI-assisted features. First, a pattern matcher that uses structured matching:

import re
import random

class PatternMatcher:
    """Match user input to response categories."""

    def __init__(self):
        self.patterns = {
            "greeting": [
                r'\b(hello|hi|hey|greetings)\b'
            ],
            "farewell": [
                r'\b(bye|goodbye|see you|farewell)\b'
            ],
            "question": [
                r'\b(what|how|why|when|where|who)\b.*\?'
            ],
        }

    def match(self, user_input):
        """Return the best matching category."""
        text = user_input.lower()
        for category, patterns in self.patterns.items():
            for pattern in patterns:
                if re.search(pattern, text):
                    return category
        return "default"


class EnhancedBot:
    """Chatbot with pattern matching and varied
    responses."""

    def __init__(self, name="PyBot"):
        self.name = name
        self.matcher = PatternMatcher()
        self.responses = {
            "greeting": [
                "Hello! How can I help?",
                "Hi there! What's on your mind?",
            ],
            "farewell": [
                "Goodbye! Happy coding!",
                "See you later!",
            ],
            "question": [
                "Good question! Let me think...",
                "That's interesting. Here's what "
                "I know...",
            ],
            "default": [
                "Tell me more about that.",
                "Interesting! Can you elaborate?",
            ],
        }

    def respond(self, user_input):
        """Generate a response based on input."""
        category = self.matcher.match(user_input)
        return random.choice(
            self.responses[category]
        )

This demonstrates regular expressions, dictionaries, classes, and the pattern-matching approach that underlies many AI systems. The chatbot uses the same principle as larger language models — matching input patterns to appropriate responses — just at a much simpler scale.

21.11 Summary

AI programming assistants are powerful tools that work best when you understand both their capabilities and their limitations. Intentional prompting — being specific, providing context, and iterating on results — produces far better output than vague requests. Always evaluate AI-generated code against a checklist before using it. And remember: the Python fundamentals you learned in earlier chapters are what allow you to judge whether AI output is correct, efficient, and secure.
