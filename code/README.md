# Code Examples

Python scripts and Jupyter notebooks for *Code Python, Consult AI*.

## Quick Start

**Option 1: Run locally**
```bash
python hello_world.py
```

**Option 2: Run in Google Colab (no install needed)**
Open any `.ipynb` file and click the "Open in Colab" badge at the top. Colab includes Google Gemini for AI-assisted coding.

## Files

Each file contains the key code example from the corresponding chapter. Files are named to match chapter topics.

## Notes

These examples are extracted from the companion book. Some are complete programs, others are starting points that the book builds on incrementally. See the book for full explanations and the chatbot project that evolves across chapters.
